# 三角洲行动 - 战术撤离 (Delta Force: Tactical Extraction)

一个使用 Three.js 制作的 3D 第一人称战术撤离射击网页游戏，类似《三角洲行动》和《逃离塔科夫》的玩法。

## 🎮 游戏特色

### 核心玩法
- **第一人称射击**：基于 Three.js 的 3D FPS 视角
- **战术撤离**：进入战场 → 搜索战利品 → 抵达撤离点
- **装备/背包系统**：多款武器和护甲，选择会影响你的战术
- **AI 敌人**：巡逻、追击、射击、命中判定（含爆头）
- **多关卡任务**：3 个不同难度和氛围的地图

### 关卡
1. **仓库突袭**（简单）- 棕色仓库风格，6 个敌人
2. **城区清剿**（中等）- 灰色城区风格，10 个敌人
3. **夜间渗透**（困难）- 黑暗夜色风格，14 个敌人

### 武器
- 🔫 **M1911 手枪**（默认）- 12发弹匣，稳定可靠

- 🔫 **M870 霰弹枪** - 6发，8颗弹丸，近战毁灭

### 护甲

- 🛡️ 中型战术甲 (100防护)
- 🛡️ 重型防弹甲 (200防护)

### 战利品类型

## 🚀 运行方式

由于使用了 ES Modules 和 importmap，需要通过 HTTP 服务器运行（不能直接打开 file://）。

### 方式 1：使用 Python 内置服务器
```bash
cd delta-force-game
python3 -m http.server 8080
```
然后浏览器访问 `http://localhost:8080`

### 方式 2：使用 Node.js
```bash
npx serve delta-force-game
```

### 方式 3：直接双击
部分浏览器允许直接打开 HTML（需要开启 ES Module 标志）。

## 🎯 游戏流程

1. **主菜单** → 点击「开始任务」
2. **装备配置** → 选择任务、武器、护甲
3. **部署** → 进入 3D 战场
4. **战斗与搜索** → 击败敌人，拾取战利品
5. **撤离** → 走到撤离点（绿色信标），按 F 启动 10 秒撤离
6. **结算** → 获得金钱奖励，存入存档
7. **解锁** → 用金钱购买更高级的武器和护甲

## 💾 存档系统

游戏使用 `localStorage` 自动保存：
- 资金
- 已解锁的武器/护甲
- 持久化的角色进度

## 🛠️ 技术栈

- **Three.js 0.160.0** - 3D 渲染
- **原生 JavaScript** - 无框架依赖
- **HTML5 Canvas** - 小地图
- **Web Audio API** - 程序化音效
- **Pointer Lock API** - 鼠标控制
- **LocalStorage** - 存档

## 🎨 设计要点

- **程序化关卡生成**：每次进入关卡都会生成不同的地图布局
- **真实弹道**：使用射线检测实现精确射击判定
- **爆头机制**：头部伤害 ×2.5
- **敌人 AI**：巡逻 / 追击 / 攻击三状态切换
- **视线检测**：敌人需要看到玩家才能追击
- **撤离机制**：需要坚守 10 秒才能成功撤离
- **物资风险**：死亡会丢失所有战利品（高风险高回报）
- **程序化音效**：使用 Web Audio API 实时生成射击/拾取/受伤音效
